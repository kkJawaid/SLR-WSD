# Comparative Tables

Working tables generated from the data extraction sheets and risk of bias assessments. These tables are used to synthesize the Results section of the manuscript, with each table answering a specific research question or PRISMA 2020 reporting requirement.

Files (to be maintained in this directory during synthesis):
- `table-raw-extraction.xlsx` — Primary dataset combining R1 and R2 extraction.
- `table-architectural-patterns.xlsx` — RQ1 (ML techniques, WSD paradigms, and PEFT progression).
- `table-lexical-integration.xlsx` — RQ2 (Corpora, WordNet, and dataset integration mechanisms).
- `table-eval-benchmarks.xlsx` — RQ3 (Generative metrics, benchmarks, and baseline comparisons).
- `table-thematic-synthesis.xlsx` — RQ1-RQ4 (Frequency and definitions of emergent themes/challenges).
- `table-risk-of-bias.xlsx` — PRISMA Item 11 (Study quality and methodological bias assessment).
